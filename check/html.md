## "<!DOCTYPE html>"
브라우저에게 "이 문서는 HTML5 문서야"라고 알려주는 선언문
이게 없으면 브라우저가 옛날 방식으로 문서를 해석해서 CSS가 깨질 수 있습니다.
모든 HTML 문서의 첫 줄에 무조건 들어갑니다.

## <html> 태그
HTML 문서 전체를 감싸는 최상위 태그
이 안에 문서 정보 <head>와 <body>가 들어갑니다.
lang 속성으로 문서의 언어도 지정합니다.

## <head> 태그
화면에 직접 보이지 않지만 브라우저와 검색엔진에게 문서에 대한 정보를 알려주는 영역

## 문자 인코딩 메타태그
<meta charset="UTF-8">은 이 문서가 어떤 방식으로 글자를 저장했는지를 의미

## viewport 메타태그
반응형 웹을 만들기 위한 태그로, 기기 화면(모바일) 너비를 CSS가 인식하는 너비로 설정해줌

## CSS 파일 연결 <link>
css 폴더 안의 스타일 시트를 문서와 연결하기 위한 태그

## body 태그 <body>
실제로 화면에 보이는 내용이 들어가는 곳

## <header> 태그
페이지 맨 위, 로고와 메뉴가 있는 영역

## 로고
보통 클릭하면 페이지 맨 위롤 이동하는 링크(<a>)로 만듭니다.
#은 페이지 맨 위로 이동을 의미
```html
<a href="#" class="logo">inho</a>
```

## <nav> 태그
이 안에 있는 링크들은 사이트 내비게이션임을 의미합니다.

## <ul>, <li> 태그
unordered list와 list item을 의미합니다.

## button의 aria-label 속성
버튼 안에 아이콘만 있고 글자가 없을 때 스크린 리더에게 이 버튼의 의미를 설명해주는 속성

## <main> 태그
페이지의 핵심 콘텐츠가 위치하는 곳을 나타내는 시맨틱 태그

## <section> 태그
문서 안에서 하나의 독립적인 구역을 나타내는 시맨틱 태그

## <article> 태그
그 자체로 독립적으로 떼어내도 말이 되는 콘텐츠

## <img> 태그
닫는 태그가 없으며 필수 속성으로 src, alt가 존재한다

## <class>와 <id> 태그
<class>태그는 한 페이지 내에서 여러 번 반복 사용할 때
<id> 태그는 한 페이지 내에서 단 하나만 고유하게 사용할 때

## <form> 태그
사용자의 입력을 받는 태그로, novalidate 속성을 넣어 브라우저의 기본 유효성 검사를 끌 수 있다.

## <label> 태그
특정 id 입력 요소와 연결시키는 태그

## <input>과 <textarea>태그
input은 한 줄짜리 입력을, textarea는 여러 줄 입력이 필요할 때 사용한다.

## <script src=... defer> 태그
JS를 HTML에 연결시키기 위한 태그이다.
defer은 html 파싱이 끝난 후 js 파일이 실행되도록 도와줌.
